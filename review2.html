Android System Settings Quick Guide

If all speech synthesis throws synthesis-failed within 10ms on an Android tablet:

  1. Open tablet Settings ⚙️ > Accessibility > Text-to-speech output.
  2. Tap "Listen to an example". If it is silent, Android's speech service is stopped.
  3. Tap ⚙️ next to Preferred Engine (Speech Services by Google) > Install voice data > Hindi. Make sure it is downloaded.
  4. If it still fails, go to Settings > Apps > Speech Services by Google > Storage > Clear Cache, then restart Chrome.
